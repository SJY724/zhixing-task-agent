# 企业知识库样例：差旅与采购制度（虚构，仅用于 RAG 演示）

## 差旅报销
1. 出差需提前在 OA 提交《出差申请》，审批通过后方可预订交通与住宿。
2. 高铁二等座、飞机经济舱为默认标准；升舱需部门负责人书面同意。
3. 住宿限额：一线城市 550 元/晚，其他城市 400 元/晚，超标部分自理。
4. 出差补助：一线城市 80 元/天，其他城市 50 元/天，按自然日计发。
5. 报销须在返程后 10 个工作日内提交发票、行程单与审批截图。

## 采购申请
1. 单笔 5000 元以下由部门经理审批；5000 元（含）以上需分管副总审批。
2. 信息化软件与云资源采购须同步会签信息安全与财务。
3. 供应商须完成年度合规审查，未入库供应商不得签订合同。
4. 紧急采购可走绿色通道，但须在 3 个工作日内补齐审批材料。
